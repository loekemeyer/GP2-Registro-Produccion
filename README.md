# Prueba login operarios

Abrir desde una PC o tablet **conectada al Wi-Fi de la planta**, poner un legajo y tocar **Probar**.

- ✅ **Funciona**: muestra operario, sede y cómo lo ve la base (debe decir `operario`).
- ❌ **Fuera de la red**: anotar la IP que muestra y avisar a Thomas (puede ser que cambió la IP de la planta).

No carga ni cambia nada. Página temporal: se borra al terminar las pruebas.
